# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Personal blog (Chinese content) built with **Astro 7** on the community theme **astro-antfustyle-theme** (AAST, lin-stephanie, antfu minimalist style). Static site deployed on Vercel (chenyubo.vercel.app). Pushing to `main` auto-deploys (Vercel needs Node 22.x runtime; local dev needs Node >= 22.12).

2026-08 整站从旧主题（Astro Theme Yi / Astro 4 + Tailwind）切换而来；旧主题时代的 `DESIGN.md`/`FEATURES.md` 仅存档。

## Commands

Uses pnpm.

```bash
pnpm install
pnpm dev      # dev server
pnpm build    # production build to dist/ (drafts excluded); postbuild runs Pagefind indexing
pnpm preview  # preview production build
```

No test suite or linter is configured.

## Architecture

**Configuration is centralized in `src/config.ts`** — three constants `SITE` / `UI` / `FEATURES` (types in `src/types.ts`). Site metadata, nav (`UI.internalNavs`), social links, and feature toggles all live here. Don't hardcode these values in components. Styling is **UnoCSS** (no Tailwind; config in `unocss.config.ts`).

**Content collections** (`src/content.config.ts`):
- `blog` — posts in `src/content/blog/*.md`, schema `postSchema` in `src/schema.ts`: required `title` (≤60 chars) + `pubDate`; optional `tags/description/subtitle/toc/lastModDate/draft/cover` etc. **No categories/sticky/series concepts** — legacy categories were merged into `tags` during migration.
- `shorts` — short status updates in `src/content/shorts/*.md` (needs `title` + `pubDate`).
- `pages/home` — homepage copy in `src/content/home/index.md`.

**Comments are Waline, not Giscus** — the theme's Giscus widget was deleted. `src/components/widgets/Waline.astro` mounts to `#waline` (server: `https://blog-waline-wheat-two.vercel.app`, reuses the previous site's data; anonymous commenting allowed). Frontmatter flag `giscus` acts as the per-post comment switch. Lifecycle: destroy on `astro:before-swap`, re-init on `astro:page-load`; dark mode follows `html.dark` via `dark: 'html.dark'`. Message board page is `/message`. Waline theme variables are aligned to the site palette in `src/styles/your.css` (`--waline-*` mapping to `--c-bg`/`--fg-deep`/`--fg-light`).

**Chinese fonts**: `--font-sans` fallback chain starts with `Noto Sans SC Variable` (npm package `@fontsource-variable/noto-sans-sc`, unicode-range sliced), imported in `src/styles/your.css`. Do NOT use the Astro fonts API for CJK — the fontsource CDN has no chinese-simplified variable single-file (404s), and Google fonts endpoints are unreachable on this network.

**OG images**: satori + sharp, built at build time (`src/utils/og-image/`, route `src/pages/og-images/[...slug].png.ts`). satori fonts are local OTFs read from `scripts/fonts/NotoSansSC-{Regular,Bold}.otf` via fs (build-time only — keep out of `public/`; Inter has no CJK glyphs so Chinese titles would be tofu without them). Template markup sets `font-family: 'Noto Sans SC'`.

**Search**: Pagefind, index generated by the `postbuild` script after `pnpm build`.

**Site-specific styles** go in `src/styles/your.css` — imported last in `src/layouts/BaseLayout.astro` so rules win the cascade (currently: Noto Sans SC import + `#waline` variable overrides).

**Theme source backup** lives in `themes/astro-antfustyle-theme` (gitignored, not part of the build) — kept for diffing against upstream when syncing theme updates.

**View Transitions / client scripts**: client-side `<script>` in `.astro` components must NOT import anything that reaches `astro:config/server` (e.g. `~/utils/path`) — it's a server-only module and breaks the client bundle. Use `location.pathname` instead.

Path aliases (tsconfig): `~` → `src/`, `~/*` used throughout the theme (e.g. `~/config`, `~/components/...`).

## Migration notes (one-off, kept for reference)

`scripts/migrate-posts.mjs` was the one-off migration script from the old theme: `date`→`pubDate`, `modDatetime`→`lastModDate`, `category` merged into `tags`, dropped `author/featured/series/seriesOrder/sticky`, split 2 overlong titles into `title` + `subtitle`. Legacy static images stay under `public/assets/images/<topic>/` and are referenced by absolute `/assets/images/...` paths in posts.
